# ERV Design Model

A public, explicitly Lakatosian research programme on endogenous retroviruses (ERVs) and ERV-like genomic elements, within the Designed Functional Maturity framework.

Human-Curated, AI-Enabled (HCAE)

## Research question

Could an originally functionally mature biosphere, including a potentially functional original biological network, followed by inheritance, viral transmission, diversification, modification and loss, plausibly account for a nontrivial subset of present ERV-like genomic patterns?

The programme's current answer is: preliminary plausibility only. See the status limits below.

## Programme status

- Status: exploratory research programme, established 2026-11-18.
- This is a public GitHub repository. It is not a journal publication and it is not peer review.
- No claim is made here that original design, an original biological network, universal noncoding functionality, or comparative explanatory parity or superiority is established.
- The strongest current comparative assessment in the curated material is in `research/COMPARATIVE-EXPLANATORY-EVALUATION-v0.1.md`: conventional reconstruction currently has stronger direct support for precise orthologous integrations and shared derived changes; the design model has not attained comparative explanatory parity or historical confirmation.
- No confirmed human or non-primate positive, other-ape negative orthologous A/B locus is asserted. Family or subfamily similarity is not an orthologous insertion.

## Scope and limits

- Curated source: the Original Biological Network (OBN) work in `jdlongmire/erv-explanatory-model`, `original-biological-network/`, publication merge PR #3, merge commit a3aaa8436d991f7fcefb0927581ca811fe1e5ce9. Full file by file provenance is in `governance/source-provenance-ledger.md`.
- Excluded by the programme firewall: material from independent parallel programmes. No findings, predictions, or verdicts from those programmes are imported here. See `governance/programme-firewall.md`.
- Theological premises are identified as premises or hypotheses in the charter. They are not presented as experimentally established facts.
- Primary publications are the evidence anchors. Unverified or inaccessible supplements are flagged as such in the curated files and must not be treated as inspected data.
