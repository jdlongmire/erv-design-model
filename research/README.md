# Research

Current programme material, drawn from the Original Biological Network (OBN) work in the source repository. See `../governance/source-provenance-ledger.md` for the file by file record of where each file came from.

## Current

- `Original_Biological_Network_Whitepaper_v0.3.md` - the current Original Biological Network whitepaper. An exploratory hypothesis, not peer reviewed; the paper itself claims no new sequence level findings.
- `Functional_Genomic_Architecture_Whitepaper_v0.1.md` - functional genomic architecture within the Original Biological Network proposal. Distinguishes demonstrated function from hypotheses about origin.
- `FORMAL-CAUSAL-MODEL-v0.1.md` - the model's starting conditions, mechanism inventory, causal sequence, and the outcomes that would count against it.
- `COMPARATIVE-EXPLANATORY-EVALUATION-v0.1.md` - a side by side comparison with the standard explanation. Current judgment: the design model does not yet match the standard explanation on this evidence, and no historical confirmation is claimed.
- `BIDIRECTIONAL-EVIDENCE-MATRIX-v0.1.md` - evidence matrix for the symmetric screening question: patterns present in one lineage group and absent in another, checked in both directions.
- `POST-FALL-CROSS-LINEAGE-EVIDENCE-REVIEW-v0.1.md` - cross-lineage evidence review.

## Audits

`audits/` holds the location audits and execution records R1 to R8, in their original form. An audit record is a record of what was checked and what was found at that date, including unresolved and unverified items. R7 and R8 in particular record limits on obtaining data and the use of alternate sources; treat any material they flag as unverified accordingly.

## History

`history/` holds superseded whitepaper revisions (Original Biological Network v0.1 and v0.2) and planning documents. They are preserved as a record and do not state the programme's current position.
