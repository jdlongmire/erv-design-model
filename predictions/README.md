# Predictions

Predictions written down and dated before the outcome data is examined are this programme's main discipline against explaining things after the fact.

Rules:

1. Copy `preregistration-template.md` to a new file named with the date and a short slug, and commit it before inspecting the outcome data for the test.
2. State the prediction, what result would count against it, the scoring rule, the genome assemblies and data versions used, and what the competing model expects, all in the same file.
3. Log every completed test, pass or fail, in `result-log.md`. Failed predictions are programme data, not embarrassments to be omitted.
4. No prediction may use findings, predictions, or verdicts from the separate parallel research efforts that this programme does not draw on. See `../governance/programme-firewall.md` for the record of that separation.

At establishment (2026-11-18) no prediction has been preregistered in this repository yet. The five predeclared test families (T1 to T5) in `../research/COMPARATIVE-EXPLANATORY-EVALUATION-v0.1.md` section 5 are the approved starting set from which the first preregistrations are to be drawn.
