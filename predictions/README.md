# Predictions

Prospective, dated, preregistered predictions are the programme's main discipline against post hoc explanation.

Rules:

1. Copy `preregistration-template.md` to a new file named with the date and a short slug, and commit it before inspecting the outcome data for the test.
2. State the prediction, the disconfirmer, the scoring rule, the assemblies and data versions, and the competing model expectation in the same file.
3. Log every completed test, pass or fail, in `result-log.md`. Failed predictions are programme data, not embarrassments to be omitted.
4. No prediction may import findings, predictions, or verdicts from a firewalled parallel programme. See `../governance/programme-firewall.md`.

At establishment (2026-11-18) no prediction has been preregistered in this repository yet. The predeclared test families T1 to T5 in `../research/COMPARATIVE-EXPLANATORY-EVALUATION-v0.1.md` section 5 are the approved starting set from which the first preregistrations are to be drawn.
