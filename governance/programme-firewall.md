# Programme Firewall

This programme is curated from one authorised source line: the Original Biological Network work in `jdlongmire/erv-explanatory-model`, `original-biological-network/`.

## Rules

- Do not copy, import, or rely on material from independent parallel ERV research programmes, including their research files, predictions, verdicts, or unpublished data.
- Do not use a result obtained under another programme's method or governance in this programme until and unless the repository owner explicitly lifts the firewall for that material in a recorded decision.
- Mentions that a parallel programme exists, in a provenance or governance record, are not an import of its findings.
- If a file's provenance cannot be shown to be the authorised source line, it does not enter this repository.

## Establishment record

At establishment on 2026-11-18 the source tree was inventoried file by file. The source repository contained no parallel programme research directory in its tree; the two source README files, which carried navigation references to parallel tracks, were not migrated. They are recorded as omitted in the provenance ledger, and their content is superseded by this repository's README and charter.
